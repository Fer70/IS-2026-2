Acerca de esta plataforma

Esta plataforma de cursos fue desarrollada para la clase de Ing de Software con el objetivo de facilitar el acceso a la educación en línea. El proyecto es una iniciativa académica que busca ofrecer una experiencia de aprendizaje intuitiva y accesible para todos los usuarios.

La meta del curso es la mejora continua y la innovación educativa.

Equipo de Desarrollo

Fernando Ocampo Tovar.

Tecnologías Utilizadas

Se utilizó tecnologías modernas como Flask para el backend, SQLAlchemy para la gestión de bases de datos, y Tailwind CSS para un diseño responsivo y atractivo.
